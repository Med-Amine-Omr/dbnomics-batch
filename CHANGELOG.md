## [0.1.0] - 2026-11-27

### Added

- Spring Boot 4.2 project with Spring Batch 6 and a JDBC job repository.
- PostgreSQL 17 service with Docker Compose.
- Configuration externalized through environment variables.
- Integration test running on PostgreSQL 17 with Testcontainers.
- GitHub Actions CI pipeline (build and tests).
- Project documentation: README, contributing guide, changelog.
